Verify it yourself

This page does not ask the server whether things were fair. It fetches the evidence and recomputes the result right here, in your browser, with the same code the game runs. If the announced number disagrees with the recomputed one, you will see it.

A run id starts with attempt_; a pull id is the plain identifier from your pull history. Results are shareable: verify.html?id=…

What is actually checked. Pull: the fingerprint of the secret is published before the roll and the secret itself afterwards; this page matches one against the other and re-derives the items from the secret. Run: the server stores your input tick by tick; this page reassembles that recording, replays the entire run and computes its own score. The floor layout is checked against the fingerprint published before the run began.
